# NOVUS – Project Specification

## Title
NOVUS – Smart Smartphone Warranty, Resale Valuation and Intelligent Resale Assistance Platform

## Core Application Lifecycle
REGISTER → TRACK → ASSESS → VALUE → SUPPORT → SELL

## Major Capabilities
1. Smartphone configuration management
2. User/device registration
3. Warranty tracking
4. Condition assessment
5. Algorithmic resale valuation
6. Historical market trend analysis
7. Local/demo resale offers
8. Smart Assistant (Internal Java Decision-Support)
9. Sell-now-or-wait decision support
10. Simulated verification
11. Simulated pickup/courier workflow
12. Simulated payment tracking
13. Persistent relational database (MySQL)
14. REST APIs
15. Java OOP implementation

## Smartphone Hierarchy
The platform uses the following hierarchical classification:
`Brand → Series → Model → Variant`

**Example:**
Apple → iPhone → iPhone 13 → iPhone 13 Pro Max → 256GB/Graphite
